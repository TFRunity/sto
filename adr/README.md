# ADR (v1)

Здесь лежат ADR, действующие в v1.

**ADR-018** (WebSocket для чата — исключение из правила «RabbitMQ только между сервисами»)
перенесён в `../v2/adr/architecture/ADR-018-chat-websocket-exception.md`: модуль Chat вынесен
в v2. Номер 018 в v1 пропущен намеренно — нумерация не сдвигалась, чтобы ссылки из диаграмм и
документов остались верными.

ADR-022…039 (30.10.2026) оформлены из решений блоков P, D, I — исходные обсуждения лежат в
`../decisions/` (`stack-`, `pattern-`, `infra-decisions-v1.md`). Пометка **«Решение А-NN»**
— конфликт, разрешённый без разработчика и затем разобранный с ним; история — `../CHANGES-v1.md`.

## Раскладка

```
adr/
├── architecture/    структура сервисов, сага, БД, паттерны
├── security/        модель доверия, секреты, RabbitMQ, периметр
├── testing/         объём тестирования, CI
├── stack/           выбор библиотек и инструментов (с 30.10.2026)
└── infrastructure/  Docker, Compose, nginx (с 30.10.2026)
```
