# ADR-032: Единый формат ошибок API; дашборд директора — «всё или ничего»

## Статус
Принято

## Контекст
Шесть сервисов и три клиента. Ошибки должны выглядеть одинаково, а
клиенты — ветвиться по стабильному коду, а не по тексту. Дашборд
директора собирает Gateway из двух параллельных запросов (Orders stats,
Users engineers-load — `sequence-director-dashboard`); нужно решить, что
отдавать при отказе одного из них.

## Решение
**Формат ошибок** — свой конверт, общий тип и хелперы в `chassis`:
```json
{"error": {"code": "order_not_paid", "message": "…", "fields": {"phone": "required"}}}
```
- `code` — стабильная машиночитаемая строка (`order_not_paid`,
  `payment_not_confirmed`, `plate_taken`, `phone_taken`, …); клиенты
  ветвятся только по нему и сами формируют тексты для пользователя.
- `message` — для разработчика и логов, не для показа.
- `fields` — ошибки валидации «поле → причина» (ADR-028).
- Наружу — только доменный код. Цепочка `%w`, текст ошибок Postgres и
  прочие детали реализации — только в логах.
- Маппинг доменной ошибки в HTTP-код — в одном месте сервиса.
- Gateway пропускает ошибки сервисов как есть, свои (`401`, `403`, `502`,
  `504`) отдаёт в том же формате.
- Формат описан в OpenAPI как общий компонент (ADR-028).

**Дашборд** — всё или ничего: `errgroup.WithContext`, первая ошибка
отменяет соседний запрос.
- Общий дедлайн на дашборд через контекст — 3 с; таймаут `http.Client` —
  страховка.
- Сервис ответил ошибкой или недоступен → `502`; не уложились в
  дедлайн → `504`.

## Альтернативы, которые рассматривались
- **RFC 9457 Problem Details** — стандарт, но часть полей формальна
  (`type` как URI, `instance`), а своё расширение `code` всё равно нужно.
  Отклонено.
- **Частичный ответ дашборда** (каждая секция — данные или ошибка) —
  сложнее контракт и фронт; частичный отказ крайне редок. Отклонено.

## Последствия
**Плюсы:** один формат для трёх клиентов; простой контракт дашборда.

**Минусы:** при недоступности одного сервиса директор не видит дашборд
целиком; формат самописный — его единообразие держится общим кодом
`chassis`.
