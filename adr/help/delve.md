# Отладка Go в Delve

Проверь, что `dlv version` работает и установленный Delve поддерживает версию
из `go version`. Для начала возьми тест Users, которому не нужна БД.

## Точка останова в тесте

Из корня репозитория:

```sh
cd users
dlv test ./internal -- -test.run '^TestLogin$/^неверный_пароль$' -test.v
```

`dlv test` собирает тестовый бинарник и открывает приглашение `(dlv)`.
Всё после `--` передаётся этому бинарнику, поэтому флаг выбора теста здесь
называется `-test.run`.

В приглашении Delve набери:

```text
break login github.com/AlexeBabanov/sto/users/internal.(*Service).Login
breakpoints
continue
args
next
locals
stack
continue
exit
```

`break login …` ставит именованную точку на вход в `Service.Login`. При первом
`continue` тест запускается и останавливается в методе. После просмотра состояния
второй `continue` даёт тесту завершиться. Для точки по строке найди нужное место
командой `rg -n 'func .*Login' internal/service.go` из каталога Users и подставь
номер исполняемой строки в `break service.go:<строка>`.

| Команда Delve | Действие |
| --- | --- |
| `continue` или `c` | Продолжить до точки останова или завершения процесса. |
| `next` или `n` | Выполнить строку, пропустив вход в вызванную функцию. |
| `step` или `s` | Войти в вызванную функцию. |
| `stepout` | Продолжить до выхода из текущей функции. |
| `args`, `locals`, `print err` | Посмотреть аргументы, локальные переменные или значение выражения. |
| `stack`, `goroutines` | Посмотреть стек текущей горутины или список горутин. |
| `list` | Показать исходник около текущей строки. |
| `clear login` | Снять точку `login`. |
| `restart` | Запустить текущий бинарник заново с теми же аргументами. |
| `rebuild` | Пересобрать и перезапустить бинарник после правки исходников. |
| `help break` | Посмотреть варианты команды, включая условные точки останова. |

Если Delve не находит функцию, выполни `funcs Login` и возьми точное имя из вывода.
Если точка поставилась, но тест прошёл мимо, проверь фильтр теста и строку
`=== RUN`. Для точки по файлу выбирай строку, которая исполняется.

## Точка останова в HTTP-сервисе

Из корня в первом терминале запусти `make dev-up SVC=users`. Цель поднимет
инфраструктуру Compose и запустит Users через Delve на хосте с настройками
из `.env`. Для уже занятого порта Users сначала установи, какой процесс его
слушает, по [памятке диагностики](diagnostics.md).

Во втором терминале подключись командой `dlv connect 127.0.0.1:2345`.
Поставь точку на `Service.Login` как выше и введи `continue`, чтобы сервис
начал принимать запросы.

В третьем терминале отправь запрос к Users напрямую:

```sh
curl -i http://127.0.0.1:8081/login \
  -H 'Content-Type: application/json' \
  -d '{"phone":"+70000000001","password":"engineer-example"}'
```

Это данные локального seed-инженера. Пока выполнение на точке останова,
`curl` ждёт ответа. Для завершения запроса введи `continue` во втором
терминале. В конце останови headless-сессию в первом терминале через `Ctrl+C`.
Инфраструктура Compose продолжит работать.
