# ADR-040: Разработка — сервис на хосте через `go run`, порты инфраструктуры только на 127.0.0.1

## Статус
Принято. Исключение для локальной разработки из инварианта ADR-010 / ADR-037 / ADR-038
(«`ports:` только у nginx и Gateway»). Не заменяет их.

## Контекст
Цикл «правка → результат» при запуске сервиса в контейнере — пересборка образа
(десятки секунд). Сервис, запущенный на хосте (`go run`), даёт цикл в секунды и прямую
работу отладчика. Но с хоста недоступны его БД, RabbitMQ и Gotenberg: портов у них нет
по ADR-010. Критерий вечера 1 в `PLAN.md` — `curl` в Users напрямую.

Рассматривались: curl из сети Docker (ADR не нарушается, но пересборка на каждую правку)
и проброс порта самого сервиса (то же отступление, но без выигрыша в скорости).

## Решение
**Инфраструктура публикует порты только на loopback** (`127.0.0.1:…`) в
`docker-compose.yml`:

| Контейнер | Хост |
|---|---|
| `users-db` | `127.0.0.1:5433` |
| `orders-db` | `127.0.0.1:5434` |
| `inventory-db` | `127.0.0.1:5435` |
| `rabbitmq` (AMQP) | `127.0.0.1:5672` |
| `gotenberg` | `127.0.0.1:3000` |

Management UI RabbitMQ (`15672`) по-прежнему не публикуется (ADR-012).

**Сервис запускается на хосте** — `make run SVC=<сервис>` после `make infra`:
- переменные берутся из `.env`, адреса заменяются на хостовые (Makefile);
- сервис слушает **только `127.0.0.1`** (`HTTP_ADDR=127.0.0.1:808x`) — иначе он виден
  в локальной сети без Gateway, и perimeter trust (ADR-010) ломается;
- соседние сервисы — тоже на хосте (`127.0.0.1:808x`); смешивать «один на хосте,
  сосед в Docker» не поддерживается: сервисы в контейнерах портов не публикуют.

Сквозной путь через nginx → Gateway и `scripts/e2e.sh` проверяются только в Docker
(`make up`).

## Альтернативы, которые рассматривались
- **curl из сети Docker** (`docker compose exec` / одноразовый контейнер в `backend`) —
  без отступления от ADR, но пересборка образа на каждую правку. Отклонено ради скорости.
- **Порт самого сервиса наружу** — то же отступление, цикл не ускоряется. Отклонено.
- **Отдельный `compose.override.yaml` с портами** — исключение изолировано в своём файле,
  но конфигурация окружения размазывается по двум файлам. Отклонено: один источник правды.

## Последствия
**Плюсы:** цикл правки в секунды; отладчик и IDE работают с процессом напрямую; с других
машин порты не видны.

**Минусы:**
- инвариант ADR-010 проверяется уже не правилом «нет `ports:`», а правилом «`ports:` вне
  nginx/Gateway — только `127.0.0.1`»;
- адреса для хоста — второй набор в Makefile рядом с compose;
- окружение на хосте отличается от контейнера: ошибки сети, DNS, non-root ловятся только
  в `make up`;
- порты `5433–5435`, `5672`, `3000` должны быть свободны на машине разработчика.

**Обязательно до любого не-локального развёртывания:** убрать `ports:` у инфраструктуры
(или вынести в dev-only конфигурацию) — иначе условие ADR-010 нарушено.
