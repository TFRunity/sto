# ADR-012: RabbitMQ — смена дефолтных кредов вместо TLS/ACL

## Статус
Принято. Уточнено 30.10.2026: способ задания кредов (раздел «Уточнение»).

## Контекст
RabbitMQ по умолчанию (официальный Docker-образ) создаёт пользователя с
логином и паролем `guest`/`guest` — общеизвестное значение, которое
проверяют в первую очередь любые автоматические сканеры при случайно
открытом порте. Открыт вопрос объёма защиты обмена сообщениями между
Orders и Users: TLS-шифрование трафика и ACL на уровне exchange/queue,
либо более лёгкая мера.

## Решение
TLS и ACL для RabbitMQ не реализуются на данном этапе. Единственная
обязательная мера — замена дефолтных кредов на собственные, через тот
же `.env`-механизм (ADR-011):

```yaml
services:
  rabbitmq:
    environment:
      RABBITMQ_DEFAULT_USER: ${RABBITMQ_USER}
      RABBITMQ_DEFAULT_PASS: ${RABBITMQ_PASSWORD}
```

### Уточнение (30.10.2026, I-05, ADR-025)
Пример выше **не работает** в нашей конфигурации: топология RabbitMQ
загружается из definitions при старте, а при импорте definitions брокер
игнорирует `RABBITMQ_DEFAULT_USER`/`RABBITMQ_DEFAULT_PASS` (поведение
задумано мейнтейнерами). Пользователь описывается внутри definitions, а
сами definitions — встроенным текстом в compose (`configs:` → `content:`)
с подстановкой `${RABBITMQ_USER}`/`${RABBITMQ_PASSWORD}` из `.env`.
Отдельного файла с паролем нет, ADR-011 соблюдён. Набросок — в ADR-038.

## Обоснование
TLS защищает от перехвата трафика внутри сети; ACL — от несанкционированного
доступа к очередям сторонним участником. Обе угрозы уже покрыты тем же
допущением, что принято для HTTP-уровня в ADR-010: герметичная
docker-сеть, порты сервисов и RabbitMQ Management UI (`15672`) не
публикуются наружу. При выполнении этого допущения добавление TLS/ACL —
не лишняя мера безопасности, а дублирование защиты от угрозы, уже
закрытой на уровне сетевой изоляции.

## Пересмотреть, если
- В docker-сети когда-либо появится третий, недоверенный контейнер
  (например, случайно подключённый отладочный инструмент).
- Management UI или порт AMQP (`5672`) будет опубликован наружу.
- Допущение о герметичности сети (ADR-010) будет пересмотрено.
