# Лабораторная работа № 4. Инструкция пользователя СТО

| Роль | Где работает | Что покажем |
| --- | --- | --- |
| Клиент | Веб | Регистрация, вход, добавление автомобиля, запись на сервис и история заказов |
| Инженер | Android | Вход, пул заявок, взятие заявки в работу и список своих заказов |
| Директор | Веб | Вход, фильтрация заказов и сводка по заказу |

## Подготовка

- Если стенд ещё выключен, запустите из корня проекта `make up`. Команда собирает образы и запускает контейнеры, а сервисы применяют миграции к локальным БД. Веб откроется на [Главной](http://sto.localhost/). Для первого запуска пригодится [инструкция проекта](../stuff/RUNNING.md#2-первая-настройка-один-раз).
- Откройте веб клиента и директора в двух профилях браузера или в обычном и приватном окнах. Начните с новой учётной записи клиента и свободных госномера и VIN.
- Для всей демонстрации используйте одну заявку. Запишите полный UUID заказа из адреса клиентской карточки, UUID автомобиля и госномер. Придумайте короткий отличительный комментарий для заявки, например «ЛР4–6, демонстрация», чтобы найти её в пуле инженера.
- Если параллельно снимаете результаты для [лабы 5](lab5.md), выполните SQL для пула до нажатия «Взять в работу».

## Android по USB

Если речь об USB-переходнике, нужен переходник и кабель с передачей данных. На компьютере нужны `adb` из Android SDK Platform-Tools и зависимости проекта в `frontend/mobile`. На телефоне нужен Expo Go, совместимый с Expo SDK 56. [Документация ADB](https://developer.android.com/tools/adb), [запуск проекта в Expo](https://docs.expo.dev/get-started/start-developing/).

Если зависимости ещё не установлены, выполните из корня `npm ci --prefix frontend/mobile`. Команда установит версии из lock-файла в `frontend/mobile/node_modules`.

1. Включите «Отладка по USB» в параметрах разработчика телефона, подключите его и подтвердите окно разрешения. В выводе `adb devices` у телефона должен быть статус `device`.
2. Пробросьте два порта. Первый соединяет телефон с Metro, второй — с nginx на компьютере.

   ```sh
   adb reverse tcp:8081 tcp:8081
   adb reverse tcp:8080 tcp:80
   adb reverse --list
   ```

   Если одновременно подключён эмулятор, укажите серийный номер телефона через `adb -s СЕРИЙНЫЙ_НОМЕР reverse …`. После переподключения проверьте пробросы снова. [Обратный проброс ADB](https://developer.android.com/develop/ui/views/layout/webapps/access-local-server#set-up-reverse-port-forwarding-with-adb).

3. Добавьте или замените эту строку в `frontend/mobile/.env.local`, сохранив остальные переменные.

   ```dotenv
   EXPO_PUBLIC_API_URL=http://127.0.0.1:8080/api
   ```

4. Из корня репозитория запустите Metro и откройте приложение на подключённом Android.

   ```sh
   npm --prefix frontend/mobile run android -- --localhost
   ```

   В этом проекте скрипт `android` вызывает `expo start --android`. Если Metro уже работал, перезапустите его после смены адреса API. [Скрипт проекта](../frontend/mobile/package.json), [Expo CLI](https://docs.expo.dev/more/expo-cli/).

Если телефон отображается как `unauthorized`, разблокируйте его и подтвердите отладку. Если открылась форма входа, но она выдаёт сетевую ошибку, проверьте на телефоне `http://127.0.0.1:8080/`. При рабочем пробросе в браузере открывается веб СТО через тот же nginx.

## Клиент

### 01. Регистрация

1. Откройте [Регистрацию клиента](http://sto.localhost/register). Введите имя, свободный телефон и пароль.
2. Нажмите «Зарегистрироваться». Откроется [«Мои заказы»](http://sto.localhost/customer).

**Скриншоты** — форма регистрации со скрытым паролем и первый экран кабинета.

### 02. Вход

1. Выйдите из кабинета кнопкой «Выйти».
2. На [странице входа](http://sto.localhost/login) введите телефон и пароль из сценария 01. Нажмите «Войти».
3. Проверьте, что открылись [«Мои заказы»](http://sto.localhost/customer).

**Скриншот** — форма «Вход в личный кабинет» перед нажатием «Войти».

### 03. Добавление автомобиля

1. В [кабинете клиента](http://sto.localhost/customer) нажмите [«Добавить ТС»](http://sto.localhost/customer/vehicles/new).
2. Введите свободный госномер кириллицей, например `А123ВС77`, выберите марку из справочника и введите свободный VIN из 17 символов, например `JT2BF22K1X0123456`.
3. Нажмите «Добавить ТС». Откроется карточка по пути `/customer/vehicles/<UUID_ТС>`. Запишите UUID из адреса.

**Скриншоты** — заполненная форма и карточка автомобиля.

### 04. Запись на сервис и история заказов

1. В карточке автомобиля нажмите «Записаться на сервис». Откроется `/customer/vehicles/<UUID_ТС>/booking`. С главной кабинета туда же можно перейти через [выбор автомобиля](http://sto.localhost/customer/booking).
2. Укажите желаемую услугу, например «Замена масла», дату не раньше сегодняшней и комментарий. Нажмите «Отправить заявку».
3. Откроется карточка `/customer/orders/<UUID_ЗАКАЗА>`. Скопируйте полный UUID из адреса. Вернитесь в [«Мои заказы»](http://sto.localhost/customer) и найдите заявку со статусом «Заявка».

**Скриншоты** — заполненная форма, карточка новой заявки и её строка в «Моих заказах». Для лабы 5 это точка запуска запроса 1.

## Инженер

### 05. Вход на Android

1. На экране входа в приложение «СТО · Инженер» введите телефон `+70000000001` и пароль `engineer-example`.
2. Нажмите «Войти». Откроется «Пул заявок». [Тестовая учётная запись](../users/migrations/00002_seed_staff.sql#L1).

**Скриншот** — «Пул заявок» после входа.

### 06. Взятие заявки в работу

1. В «Пуле заявок» найдите свою заявку по услуге, дате и комментарию из сценария 04. Снимите экран до назначения и при совмещённом прогоне выполните запрос 2 из лабы 5.
2. В строке заявки нажмите «Взять в работу». Откроется «Заказ …». Сверьте первые восемь символов номера на экране с UUID, записанным в сценарии 04.
3. Нажмите «Назад». В «Моих заказах» на вкладке «Активные» найдите тот же заказ. Нажмите «К пулу заявок» и убедитесь, что прежней заявки больше нет. Выполните запросы 2 и 2а из лабы 5.

**Скриншоты** — заявка до назначения, карточка принятого заказа и тот же заказ на вкладке «Активные».

## Директор

### 07. Вход под директором

1. В отдельном окне откройте [«Вход в личный кабинет»](http://sto.localhost/login).
2. Введите телефон **`+70000000002`** и пароль **`director-example`**. Нажмите «Войти». Откроется [кабинет директора](http://sto.localhost/director). Данные относятся к локальному тестовому стенду с применённой миграцией Users. [Тестовая учётная запись](../users/migrations/00002_seed_staff.sql#L1).

**Скриншот** — кабинет директора после входа.

### 08. Фильтрация заказов и сводка

1. Откройте [«Все заказы»](http://sto.localhost/director/orders). В поле «Имя, телефон или госномер» введите госномер из сценария 03, выберите статус «В работе» и нажмите «Найти».
2. В строке нужного заказа нажмите «Сводка». Сверьте UUID заказа, клиента, госномер, инженера и статус. Затем можно открыть «Детали» по пути `/director/orders/<UUID_ЗАКАЗА>`.
3. В списке переключите статус на «Заявка» и нажмите «Найти». Заказ с этим UUID больше не попадает под фильтр. Верните статус «В работе» для запроса 3 из лабы 5.

**Скриншоты** — отфильтрованный список с заказом и открытая «Сводка заказа».
