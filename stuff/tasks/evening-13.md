# Вечер 13 — дашборд и поиск заказов директора

**Итог вечера:** директор видит сводку и находит заказы по имени клиента,
телефону или госномеру. Gateway собирает данные сервисов с общим дедлайном.

Схемы: `sequence-director-dashboard`, `sequence-director-orders`.
ADR-019, 028, 031, 032, 033, 039.

**Перед вечером — агент:** OpenAPI внешних и внутренних маршрутов, SQL
для метрик, поиска, пагинации и выдачи данных по пачке ID. Сверить состав
метрик с дизайном директора: сегодня, в работе, ожидают оплаты, выручка
по `paid` и загрузка инженеров согласно диаграмме.

## [ ] 1. Подготовить внутренние источники

Orders отдаёт метрики для дашборда и отфильтрованные страницы заказов.
Users отдаёт данные для загрузки инженеров, ищет клиента по имени и
телефону и возвращает краткие данные пользователей по пачке ID.
Vehicle ищет ТС по номеру, применяя ту же нормализацию, что при записи,
и отдаёт номера по пачке ID. Поиск и пакетная выдача для истории включают
удалённые записи, SQL помечается `-- include-deleted`.

**Проверка:** фильтры Orders работают с пагинацией. Исторический заказ
находится по удалённому клиенту или ТС. Слишком широкий поиск даёт
`422 search_too_broad` по ADR-039.

## [ ] 2. Собрать дашборд в Gateway

На `GET /dashboard` для директора создай контекст с общим дедлайном 3 с.
Через `errgroup.WithContext` параллельно запроси `/orders/stats` в Orders
и `/users/engineers-load` в Users. Собери ответ после завершения обоих
вызовов. Ошибка источника даёт 502, истечение общего дедлайна — 504.
У каждого HTTP-клиента также есть ограничение времени.

**Проверка:** ответ содержит обе части. При отказе одного сервиса Gateway
отменяет соседний запрос и отдаёт ошибку в общем конверте.

## [ ] 3. Собрать поиск заказов

На `GET /director/orders?status=&q=&page=` при наличии `q` сначала
параллельно получи ID клиентов и ТС. Если обе выборки пусты, верни
пустую страницу. Иначе запрашивай страницу у Orders, где применяются
фильтры по статусу и совпадение по клиенту **или** ТС.
Для полученной страницы собери уникальные ID клиентов, инженеров и ТС,
параллельно загрузи данные Users и Vehicle пакетами и склей ответ по ID.
Общий дедлайн и ошибки работают так же, как у дашборда.

**Проверка:** запросы по имени, телефону и номеру находят заказ.
Проверь пустой поиск, две страницы результатов, отказ источника и дедлайн.
