# Фронтенд · Вечер 2 — Вход и кабинеты

**Итог вечера:** Клиент регистрируется, директор входит, веб открывает подходящий кабинет.

Задачи идут по порядку. После каждой сверяем результат с проверкой.

## [ ] 1. Вход и регистрация

Подключить `POST /login` и `POST /register`. Показать `error.fields` у полей, блокировать повторную отправку.

**Проверка:** Работают регистрация, вход, ошибка пароля и конфликт занятого телефона.

Веб-формы подключены. В режиме `make web` Next.js направляет `/api/*` в nginx.
Проверка форм с работающим Gateway остаётся открытой.

---

## [ ] 2. Сессия и навигация

Определить, как веб восстанавливает сессию и передаёт авторизацию Gateway. Связать вход с layout’ами ролей, реализовать выход и очистку кэша запросов при смене сессии.

**Проверка:** После выхода и после 401 защищённый экран возвращает ко входу. После входа другим пользователем данные прежней сессии не появляются.

Веб хранит токен в `sessionStorage` вкладки. Роль из JWT используется для
навигации, а права проверяет Gateway. Браузерная проверка сессии остаётся открытой.

---

## [ ] 3. Каркас мобилки

Создать отдельное приложение React Native в `frontend/mobile/`. Подключить контракт Gateway и вход инженера.

**Проверка:** Инженер входит и попадает на экран пула, выход возвращает ко входу.

Добавлены Expo-каркас, вход и чтение пула через Gateway. Команда `make mobile`
запускает приложение в Android-эмуляторе. Проверка на эмуляторе остаётся открытой.
