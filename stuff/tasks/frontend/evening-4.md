# Фронтенд · Вечер 4 — Пул инженера и работа с заказом

**Итог вечера:** Инженер берёт заявку клиента и ведёт заказ через React Native.

Задачи идут по порядку. После каждой сверяем результат с проверкой.

## [ ] 1. Пул и взятие в работу

Подключить список `requested` и claim. После успешного взятия обновить пул и открыть заказ.

**Проверка:** Заявка исчезает из пула, детали показывают активный заказ. При конфликте пул перечитывается.

В React Native подключены взятие заявки и переход в карточку заказа.
При конфликте или отсутствии заявки приложение перечитывает пул.
После возврата из карточки пул загружается заново. Проверка на
Android-эмуляторе через живой Gateway остаётся открытой.

---

## [ ] 2. Позиции и этапы

Подключить подбор товара и услуги из каталогов, добавление позиции, смену этапов и отмену с подтверждением.

**Проверка:** Позиции и итоговая сумма обновляются из API. При конфликте экран перечитывает заказ.

В карточку заказа подключены каталоги товаров и услуг, выбор позиции с
количеством, смена этапа и подтверждение отмены. После изменения или
конфликта карточка загружает заказ заново. Проверка на Android-эмуляторе
через живой Gateway остаётся открытой.

---

## [ ] 3. Фотофиксация

Подключить карточку ТС, просмотр защищённых фото, камеру с превью и загрузку multipart с `photo` и `order_id` для снимка из заказа.

**Проверка:** Снимок виден в галерее. Ошибка загрузки позволяет повторить отправку.

Карточка ТС открывается из заявки и заказа. Обложку и галерею приложение
загружает с токеном инженера. Из заказа доступна камера, предпросмотр,
повторная съёмка и отправка JPEG вместе с `order_id`. После отправки
карточка перечитывается. Проверка камеры и загрузки на Android через живой
Gateway остаётся открытой.
