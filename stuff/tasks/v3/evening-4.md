# СТО v3 · Вечер 4 — Chat и поддержка

**Итог вечера.** Клиент, инженер и директор обмениваются сообщениями в своих диалогах и видят, когда собеседник их прочитал.

## Бэкенд

### [ ] 1. Модель диалогов и HTTP

Подключить Chat, отдельную БД, миграции и маршруты Gateway. Реализовать открытие, список, историю, отправку сообщений и отметку о прочтении. Диалог клиента с инженером привязан к заказу и его ответственному, диалог директора с инженером постоянный, поддержка направляется директору из конфигурации. Уточнить проверку ответственного относительно старой sequence и поведение после его смены. Проверять участие во всех операциях с диалогом.

**Проверка.** Каждая пара открывает свой диалог, повторное открытие возвращает тот же диалог. Посторонний пользователь не получает историю или список чужих диалогов. [Сценарии Chat](../../v2/TODO.md#1-chat)

---

### [ ] 2. Доставка через WebSocket

Подключить авторизованный WebSocket через Gateway для новых сообщений и прочитанности. Через HTTP отдавать историю и состояние прочитанности для восстановления после обрыва. [ADR-018](../../v2/adr/architecture/ADR-018-chat-websocket-exception.md)

**Проверка.** Подписчик получает события сообщения и прочтения, посторонний пользователь не получает события. HTTP выдаёт актуальное состояние после разрыва.

## Фронтенд

### [ ] 1. Веб, Android и вход в поддержку

Добавить список и открытый диалог клиенту и директору. В RN подключить вкладку «Чат», список с индикатором непрочитанного и отдельный экран диалога. Из окончательной ошибки справки открыть поддержку. [Макеты и sequence v2](../../v2/README.md)

**Проверка.** Клиент переписывается с инженером по заказу, инженер с директором — в постоянном диалоге, а обращение из справки открывается у директора в поддержке.

### [ ] 2. Обновление открытого диалога

Подключить WebSocket для входящих сообщений и прочитанности. После переподключения перечитать историю, список диалогов и серверные индикаторы непрочитанного.

**Проверка.** Сообщение и прочитанность видны без ручной перезагрузки. После обрыва пропущенные сообщения появляются в истории.
