# СТО v3 · Вечер 5 — Уведомления и доставка сообщений

**Итог вечера.** Android получает уведомления о заявках и сообщениях. Сервисы восстанавливают работу с RabbitMQ внутри процесса, а контракты доставки Reports готовы к реализации.

## Бэкенд

### [ ] 1. События и отправка push

Выбрать провайдер push, описать API регистрации устройства и клиентский payload. Подключить события о новой заявке из Orders и новом сообщении из Chat. Определять получателей по правам и настройке профиля перед отправкой.

**Проверка.** Оба события отправляются зарегистрированным получателям с включённой настройкой. Чужой пользователь не получает сведения о диалоге.

---

### [ ] 2. Переподключение RabbitMQ

Доделать супервизор в `chassis` по ADR-025 и подключить его там, где сервисы публикуют и потребляют сообщения. Сохранять неподтверждённые записи в outbox до восстановления, подтверждать обработку после коммита. [ADR-025](../../adr/stack/ADR-025-rabbitmq-amqp091.md)

**Проверка.** При перезапуске брокера HTTP остаётся доступен. После восстановления накопленная запись отправляется, повторная доставка не дублирует бизнес-операцию.

---

### [ ] 3. Подготовить обмен данными Reports

Описать команду запроса данных и событие ответа, привязку к ID запроса, очереди команд Orders и Users и очередь `reports.data`. Согласовать дедлайн и лимит повторов, определить, какие данные запрашивает каждый тип отчёта. [Sequence Reports](../../v2/uml/sequence/sequence-report.drawio) · [ADR-005](../../adr/architecture/ADR-005-outbox-pattern.md)

**Проверка.** Для всех трёх типов записаны источники и схема обмена. Из контракта видно, когда ответ завершает запрос и что происходит при дубликате или таймауте.

## Фронтенд

### [ ] 1. Регистрация устройства и переход из уведомления в RN

Запросить разрешение Android и подключить регистрацию устройства по API. Обработать тап по уведомлению, проверить сессию и открыть заказ или диалог через защищённое чтение. [Макет RN v2](../../v2/design/react-native/react-native-design-v2.md#push-уведомления)

**Проверка.** На устройстве приходят уведомления обоих видов, тап открывает нужный экран. Отключённая настройка предотвращает доставку. При истёкшей сессии приложение ведёт на вход.

## Инфраструктура

### [ ] 1. Топология очередей Reports

Подготовить определения очередей и привязок в Compose по согласованному контракту.

**Проверка.** После запуска брокер загружает топологию. Очереди команд и `reports.data` доступны сервисам.
