# СТО v3 · Вечер 6 — Reports и статистика сотрудников

**Итог вечера.** Директор формирует три отчёта, повторно открывает сохранённые данные и разворачивает заказы на экране сотрудника.

## Бэкенд

### [ ] 1. Reports и асинхронная обработка

Подключить сервис, миграции, API директора и потребителей Reports, Orders и Users по контракту пятого вечера. Создавать `report_requests` и outbox одной транзакцией. При получении полного ответа атомарно сохранить снапшот и `received`. При таймауте повторять запрос в пределах лимита, затем перевести его в `failed`. [Задачи Reports v2](../../v2/TODO.md#2-reports)

**Проверка.** Запрос проходит `pending → received`. Дубль ответа не меняет сохранённые данные. При отсутствии ответа фиксируются повторы и финальный `failed`.

---

### [ ] 2. Сбор данных для трёх отчётов

Подключить отчёты «Выручка за период» с разбивкой по дням, «По сотрудникам» и «По справкам/заказам». Для выручки использовать сохранённые цены и момент подтверждения оплаты. Согласовать часовой пояс, обработку старых заказов и правила зачёта выручки нескольким исполнителям. Добавить недостающие sequence и маршруты чтения в Gateway.

**Проверка.** API возвращает итог и строки для каждого типа и периода. После правки каталога повторное чтение возвращает тот же снапшот.

---

### [ ] 3. Выдача статистики сотрудников

Взять список сотрудников из Users и статистику из Reports по `order_engineers`. Выдать роль, дату начала работы, число заказов, выручку и заказы за месяц. Проверить текущую композицию дашборда из Orders и Users. [Sequence сотрудников](../../v2/uml/sequence/sequence-employee-stats.drawio) · [ADR-020](../../adr/architecture/ADR-020-responsible-engineer-and-executors.md)

**Проверка.** Число заказов и выручка в API сверяются с отчётом за тот же период, включая заказ с несколькими исполнителями.

## Фронтенд

### [ ] 1. Список и детали отчётов директора

В вебе подключить создание отчёта с выбором периода, список с фильтром и детали для трёх типов. Отобразить серверные состояния ожидания и ошибки, итог и таблицу для готового отчёта. [Макеты директора](../../v2/design/web-director/director-web-design-v2.md)

**Проверка.** Директор запрашивает каждый тип за выбранный период и повторно открывает результаты из списка.

### [ ] 2. Экран сотрудников

Показать поля сотрудника, число заказов и выручку по данным API. Добавить разворачивание заказов на карточке.

**Проверка.** Карточка сотрудника раскрывает заказы за тот же период, что и показанная статистика.

## Инфраструктура

Добавить Reports и его отдельную БД в Compose. Подключить подготовленную топологию RabbitMQ.

**Проверка.** Reports запускается в Compose и получает ответы через `reports.data`.
