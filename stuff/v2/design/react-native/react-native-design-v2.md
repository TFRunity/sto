# react-native-design (v2)

Части RN-дизайна, вынесенные из v1 (19.10.2026): вкладка «Чат» и её экраны.

## Навигация верхнего уровня (полная)

```
┌─────────┬─────────┬─────────┐
│ Заказы  │  Чат    │ Профиль │
└─────────┴─────────┴─────────┘
```

## Экраны

### 6. Чат — список диалогов
Сервис: Chat.
Диалоги с клиентами (аватар-инициалы, привязка к номеру заказа в
превью последнего сообщения) и с директором (отдельная иконка вместо
инициалов). Непрочитанное — точка-индикатор.

### 7. Чат — диалог
Сервис: Chat.
Сообщения собеседника слева (нейтральный фон), свои — справа
(`bg-accent-muted`). Привязка к заказу в шапке. Поле ввода 44px +
кнопка отправки.

## Push-уведомления

Источники: Orders ("Новый заказ #… ожидает мастера" — не "назначен
вам", так как заказы берут сами мастера, не получают по назначению),
Chat (новое сообщение).
Тап по уведомлению → диплинк на конкретный экран (заказ или диалог).
