# web-design (v2)

Части веб-дизайна, вынесенные из v1 (19.10.2026): чат клиента и пункты навигации
«Отчёты» / «Чат» / «Чаты».

## Навигация директора (полная)

```
Дашборд · Заказы (Все заказы / Ожидают оплаты) ·
Отчёты (Список отчётов / Сотрудники) ·
Каталог (Товары (склад) / Услуги) · Чат
```

Состояние dropdown «Отчёты» открыт → «Список отчётов» / «Сотрудники».

## Навигация клиента (полная)

```
Мои заказы · Справки · Чаты
```

## Экраны

### 5. Чаты (веб-версия)
Сервис: Chat.
Двухколоночный лейаут (список диалогов слева, открытый диалог справа)
— отличается от single-screen подхода в React Native, характерного
для десктопа. Список включает диалоги с инженерами (привязка к
заказу в превью; собеседник — ответственный инженер заказа) и
отдельный пункт "Поддержка" (сценарий из certificate: после исчерпания
retry-попыток справки; на той стороне — директор).
