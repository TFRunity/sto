# Вечер 8 — Vehicle: добавить ТС и открыть карточку

**Итог вечера:** клиент добавляет ТС через nginx → Gateway → Vehicle, инженер
открывает карточку по выданному ID.

Схемы: `sequence-add-vehicle`, `sequence-vehicle-card`. ADR-019, 024, 028, 031, 033, 037, 038.

**Перед вечером — агент:** OpenAPI для `POST /vehicles` и `GET /vehicles/{id}`,
новая миграция Vehicle, запросы и конфиги генерации, подключение Vehicle и его
PostgreSQL к Compose. Клиентские проверки выполняются через API.

## [x] 1. Поднять каркас Vehicle

Используй запуск Inventory как образец. В `main` загрузи конфигурацию,
подключи отдельный пул PostgreSQL, примени миграции, собери strict-хендлер
и запусти HTTP-сервер через `chassis/httpx`. В Gateway добавь upstream Vehicle
и правила по маршруту и методу. Gateway выставляет идентичность из токена.

**Проверка:** сервис поднимается с чистой БД, healthcheck проходит, защищённый
запрос через nginx без токена получает 401.

## [x] 2. Добавить ТС

`POST /vehicles` принимает номер, марку и VIN. Из доверенной идентичности
получи `owner_id`, перед записью нормализуй госномер отдельной доменной
функцией. Репозиторий вставляет строку с UUID. Частичный уникальный индекс
по номеру среди живых записей решает гонку двух вставок. Ошибку именно этого
индекса переведи в `409 plate_taken`, успех — в `201` с `vehicle_id`.

**Проверка:** номера, которые нормализуются одинаково, дают 201 и 409.
В строке БД записан владелец из токена.

## [x] 3. Прочитать карточку

`GET /vehicles/{id}` читает живую запись из Vehicle и возвращает данные ТС.
Маршрут доступен клиенту для своей карточки и инженеру в рамках доступа к ТС.
Роль проверяет Gateway, принадлежность карточки клиенту проверяется по
`owner_id` в Vehicle. Отсутствующий или удалённый ID даёт 404. Этап работ
принадлежит заказу. История появится в вечере 11, фото — в вечере 9.

**Проверка:** добавить ТС клиентом, открыть карточку тем же клиентом и инженером,
проверить недоступность карточки постороннему клиенту и 404 по неизвестному ID.

Результаты прогона и детали проверок — в [Task_06](../help/Task_06/README.md#прогон-через-nginx).
