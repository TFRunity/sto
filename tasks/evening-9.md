# Вечер 9 — Vehicle: обложка и фотофиксация

**Итог вечера:** клиент меняет обложку своего ТС, инженер добавляет снимок в
рабочую галерею, карточка позволяет получить оба вида фотографий.

Схемы: `sequence-replace-photo`, `sequence-photofix`, `sequence-vehicle-card`.
ADR-019, 029, 032, 037, 038.

**Перед вечером — агент:** multipart-контракты, миграция для обложки и галереи,
SQL смены обложки и добавления снимка, том Vehicle и правила Compose.

## [ ] 1. Принять и проверить файл

Используй один путь декодирования для обоих хендлеров. До разбора multipart
ограничь тело через `http.MaxBytesReader` примерно до 3,5 МБ. Прими поле
`photo`, определи тип по содержимому, разреши JPEG и PNG. Сначала
`DecodeConfig` и проверка размеров, затем декодирование и перекодирование
в JPEG без метаданных. Размеры изображения ограничь в рамках ADR-029.
При превышении лимита тела возвращай 413 в конверте проекта.

**Проверка:** JPEG и PNG проходят, HEIC, текст под именем JPEG, слишком
большое тело и слишком большие размеры изображения отклоняются.

## [ ] 2. Записать обложку и снимок

`PUT /vehicles/{id}/cover_photo` доступен владельцу ТС и обновляет ключ
обложки. `POST /vehicles/{id}/photos` доступен инженеру и создаёт отдельную
запись галереи с опциональным `order_id` согласно схеме. В обоих случаях
сгенерируй UUID для имени файла, запиши JPEG в том Vehicle, затем сохрани
ключ в БД. При ошибке сохранения удали новый файл. Старую обложку можно
очистить после успешного обновления ссылки, когда она больше не используется.

**Проверка:** при ошибке БД новый файл удаляется. Замена обложки не меняет
галерею, добавление снимка не меняет обложку.

## [ ] 3. Отдать изображения через приложение

В карточке верни ссылки через Gateway. Vehicle находит ключ по записи ТС
или фото, проверяет доступ и отдаёт JPEG из тома через `http.ServeFile`.
Для входного параметра маршрута используй ID ресурса, путь к файлу
бери из БД. Nginx сохраняет лимит 4 МБ.

**Проверка:** скачать обложку и снимок через nginx, проверить маршруты
с токенами клиента и инженера и недоступность чужой фотографии.
